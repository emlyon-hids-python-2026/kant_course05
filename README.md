# kant-course05

Python programming course exercises and demonstrations repository for course 05.

## Installation

```bash
git clone https://github.com/emlyon-hids-python-2026/kant_course05.git
cd kant_course05
uv sync
```

## Usage

Run the project command:

```bash
uv run kant-course05
```

Open the demonstration notebook:

```bash
uv run jupyter notebook notebooks/demo.ipynb
```

Useful development commands are available through `make`:

```bash
make help
make install
make lint
make format
```

## Project structure

- `data/`: Datasets (not tracked by Git)
- `notebooks/`: Jupyter notebooks
- `scripts/`: Python scripts
- `src/kant_course05/`: Python package
- `Makefile`: Common development commands
